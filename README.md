# Project Abyssal Rift — Island Map (v0.4)

แมพเกาะ isometric สำหรับเกมเว็บ ใช้ **Phaser 3.90.0** (WebGL) — ไฟล์ Phaser อยู่ใน `lib/` แล้ว ไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีเปิด
- **ออนไลน์/หลายคน:** ดับเบิลคลิก `start-server.bat` (ดูหัวข้อ v1.0)
- ดับเบิลคลิก `index.html` (Chrome / Edge) ก็เล่นได้เลย
- หรือเปิดผ่าน local server เช่น VS Code → Live Server

```
js/buildings.js       ★ รายการอาคาร (ราคา/ขนาด/จำนวน/TH ที่ปลดล็อก) + กติกาวาง + ระบบเมือง/บันทึก
js/buildingArt.js     วาดภาพอาคาร isometric แบบ procedural (ภาพชั่วคราว)
js/main.js            boot: โหลด texture → bake เกาะ → สร้าง Phaser.Game + HUD
assets/terrain/       texture พื้น 3 แบบ (ต่อกันไร้รอยต่อ) + textures.js (ฉบับฝังเป็น data URL)
tools/embed_textures.py  สร้าง textures.js ใหม่หลังเปลี่ยนภาพพื้น
```

## ชั้นของเกาะ (วาดจากหลังมาหน้า)
1. ฉากหลังหุบเหว (ม่วงเข้ม + ดาว + หมอก)
2. ใต้เกาะลอยฟ้า (หินจางหายลงหุบเหว)
3. ชั้นล่างริมแม่น้ำ + แม่น้ำ (น้ำตกไหลตกหุบเหวที่ปลายทั้งสองข้าง)
4. หน้าผา + มอสที่ขอบ
5. ที่ราบ = `grass` เป็นพื้นหลัก, `grassdirt` เป็นหย่อม, `dirt` เป็นลานเมือง/ถนน/สนามรบ (ผสมด้วย splat mask)
6. สะพานหิน + แท่น Rift Portal (จุดเกิดบอส)
7. ต้นไม้ ภูเขา หิน น้ำตก Portal (เรียงตามความลึก)
8. Overlay: กริด, โซน, ทางบอส, ช่องที่ชี้

## สูตร isometric (tile 128×64)
```
worldX = (gx - gy) * 64
worldY = (gx + gy) * 32
gx = (worldX/64 + worldY/32) / 2
gy = (worldY/32 - worldX/64) / 2
```

## ผังโซน (ระยะแบบ Chebyshev จากศูนย์กลาง 29,29)
| โซน | ระยะ | ปลดล็อก |
|---|---|---|
| ใจกลางเมือง (Town Hall 4×4) | ≤ 5.5 | TH 1 |
| เขตเมืองชั้นใน | < 12.5 | TH 1 |
| แนวกำแพง/ป้อม (มีประตู 4 ทิศ) | = 12.5 | TH 1 |
| สนามรบ (ฝั่งสะพาน) | > 12.5 | TH 1 — วางสิ่งป้องกันเท่านั้น |
| เขตขยาย A / B / C | > 12.5 | TH 5 / 10 / 15 |

แก้ชื่อ สี และเลเวลปลดล็อกได้ที่ `AR.CONFIG.zones`

## v1.0 — Guest Login + เซิร์ฟเวอร์/ฐานข้อมูล + รางวัลประจำวันปราสาท
### เล่นออนไลน์ (หลายคน)
1. ติดตั้ง **Node.js 22 LTS ขึ้นไป** (https://nodejs.org) — ไม่ต้อง npm install อะไรเพิ่ม
2. ดับเบิลคลิก **start-server.bat** → เปิดเบราว์เซอร์ที่ http://localhost:3000 ให้อัตโนมัติ
3. หน้าต่างเซิร์ฟเวอร์จะแสดงลิงก์ `http://<IP เครื่องนี้>:3000` → ส่งให้เพื่อนที่อยู่ Wi-Fi/LAN เดียวกันเปิดเล่นได้เลย
   (ถ้าเพื่อนเข้าไม่ได้ ให้กด Allow ใน Windows Firewall ตอนเปิดเซิร์ฟเวอร์ครั้งแรก)
- **Guest Login**: กด "เล่นแบบ Guest" ได้บัญชีทันที · เบราว์เซอร์จำ token ไว้ → ครั้งต่อไปกด "เล่นต่อ" เข้าเมืองเดิม
- **ฐานข้อมูล**: SQLite ที่ `server/data/abyssal.db` (Node 22.13+) · ถ้า Node เก่ากว่าจะใช้ `server/data/abyssal.json` แทน
- ปุ่ม 👥 มุมขวาบน: รายชื่อผู้เล่นทั้งหมด (ออนไลน์/ล่าสุด, Lv ปราสาท, พลัง) + เปลี่ยนชื่อ · จุดเขียว = บันทึกบนเซิร์ฟเวอร์สำเร็จ
- เปิด `index.html` จากไฟล์ตรง ๆ ยังเล่นได้ในโหมดออฟไลน์ (เก็บในเบราว์เซอร์)

| API | ใช้ทำอะไร |
|---|---|
| `POST /api/guest` | Guest Login (ส่ง token เดิม = เข้าเมืองเดิม) |
| `PUT /api/state` | บันทึกเมือง |
| `GET /api/players` | รายชื่อผู้เล่น |
| `POST /api/name` | เปลี่ยนชื่อ |
| `POST /api/daily` | รับรางวัลประจำวันปราสาท (ตรวจที่เซิร์ฟเวอร์) |

### ⭐ ออนไลน์ถาวร ฟรี: Cloudflare Workers + D1 (แนะนำ)
ลิงก์ถาวร `https://abyssal-rift.<บัญชีคุณ>.workers.dev` · เปิด 24 ชม. ไม่ต้องเปิดคอมทิ้งไว้
1. สมัครบัญชี Cloudflare ฟรี: https://dash.cloudflare.com/sign-up
2. ดับเบิลคลิก **deploy-cloudflare.bat**
   - เปิดเบราว์เซอร์ให้ล็อกอิน → กด **Allow** (ครั้งแรกครั้งเดียว)
   - ครั้งแรกถ้าถามชื่อ workers.dev subdomain → พิมพ์ชื่อ (เช่นชื่อตัวเอง) แล้ว Enter
3. จบแล้วจะเห็นลิงก์ `.workers.dev` → ส่งให้เพื่อนเล่นได้เลย
- ฐานข้อมูล D1 ถูกสร้างอัตโนมัติตอน deploy ครั้งแรก · ตารางสร้างเองตอนมีคนเข้าครั้งแรก
- แก้เกมแล้วอยากอัปเดต → ดับเบิลคลิก deploy-cloudflare.bat อีกครั้ง (ข้อมูลผู้เล่นยังอยู่)
- เปลี่ยนชื่อหน้าลิงก์: แก้ `"name"` ใน `wrangler.jsonc` (ชื่อใหม่ = Worker ใหม่ + ลิงก์ใหม่)
- คำสั่งเอง: `npx wrangler login` แล้ว `npx wrangler deploy`
- ไฟล์: `worker/index.js` (API เหมือน server/server.js) · `wrangler.jsonc` · `.assetsignore` (ไฟล์ที่ไม่อัปโหลด)
- ฟรี: 100,000 คำขอ/วัน · D1 เขียน 100,000 แถว/วัน อ่าน 5 ล้าน/วัน · เกินแล้ววันนั้นจะใช้ไม่ได้จนรีเซ็ต (07:00 น. เวลาไทย)
- รีเซ็ตรางวัลประจำวันของเกม = เที่ยงคืนเวลาไทย (`TZ_OFFSET_HOURS` ใน wrangler.jsonc)
- ข้อมูลบน Cloudflare แยกจากฐานข้อมูลบนเครื่อง (server/data) — ไม่ย้ายให้อัตโนมัติ

### เปิดให้คนอื่นเล่นผ่านอินเทอร์เน็ต ฟรี (Cloudflare Quick Tunnel)
1. ดับเบิลคลิก **start-online.bat** (ครั้งแรกจะติดตั้ง `cloudflared` ด้วย winget ให้ → แล้วดับเบิลคลิกอีกครั้ง)
2. จะเปิด 2 หน้าต่าง: เซิร์ฟเวอร์เกม + Cloudflare Tunnel
3. ในหน้าต่าง Tunnel จะมีลิงก์ `https://xxxx.trycloudflare.com` → ส่งให้เพื่อนเปิดเล่นได้ทุกที่
- ไม่ต้องมีบัญชี Cloudflare/โดเมน · ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่ · ปิดหน้าต่าง = ปิดลิงก์
- เครื่องคุณต้องเปิดค้างไว้ตลอดที่มีคนเล่น · รับได้ ~200 คำขอพร้อมกัน (พอสำหรับทดสอบกับเพื่อน)
- คำสั่งเอง: `node server\server.js` แล้วอีกหน้าต่าง `cloudflared tunnel --url http://localhost:3000`
- ต้องการลิงก์ถาวร: สมัคร Cloudflare (ฟรี) + มีโดเมน → ใช้ Named Tunnel

## โหมดสร้างอาคาร (v0.2)
- เลือกอาคารจากแถบล่าง → เงาอาคารตามเมาส์ แต่ละช่องเป็น **เขียว = วางได้ / แดง = วางไม่ได้** พร้อมบอกเหตุผล
  (นอกพื้นที่, โซนยังล็อก, ผิดโซน, ทับถนน, ทับประตูเมือง, มีต้นไม้/หิน, ทับอาคารอื่น)
- ตอนวาง ช่องที่ใช้ได้จะเรืองเขียวจาง ๆ ส่วนโซนที่ยังล็อกจะมืด
- มือถือ: แตะครั้งแรก = เล็ง, แตะซ้ำที่เดิม = วาง
- อาคารมีเวลาก่อสร้าง/อัปเกรด (แถบความคืบหน้า) และเร่งได้ด้วย Coupon
- เลเวลอาคารต้องไม่เกินเลเวล Town Hall
- Town Hall: เลเวลปลดล็อกโซน (A=TH5, B=TH10, C=TH15), อาคารใหม่ และจำนวนปาร์ตี้ (TH1=1, TH5=2, TH10=3, TH15=4, TH20=5 · ปาร์ตี้ละ 4 ฮีโร่)
- ฟาร์ม/โรงไม้/เหมือง ผลิต Silver อัตโนมัติ
- ต้นไม้/หินในเขตขยาย: คลิกช่อง → 🪓 เคลียร์ (⚪ 200)
- เมืองบันทึกใน localStorage ของเบราว์เซอร์อัตโนมัติ (ข้อมูลอยู่เฉพาะเครื่อง/เบราว์เซอร์นั้น) · ปุ่ม JSON ส่งออกทั้งแผนที่และเมือง

| กลุ่ม | อาคาร |
|---|---|
| เมือง | บ้านพัก 2×2, คลังเสบียง 2×2, น้ำพุ 2×2 |
| ผลิต | ฟาร์ม 3×3, โรงไม้ 2×2, เหมืองหิน 2×2 (TH2) |
| ฮีโร่ | หอฮีโร่ 3×3, โรงเตี๊ยม 2×2 (TH2), หอวิจัย 2×2 (TH2), โรงตีเหล็ก 2×2 (TH3), กิลด์นักล่า 3×3 (TH3) |
| ป้องกัน | กำแพงหิน 1×1 (แนวกำแพง), ป้อมธนู 1×1, กับดักหนาม 1×1 (สนามรบ, TH2), ป้อมปราการผลึก 2×2 (TH5) |

ตัวเลขทั้งหมด (ราคา เวลา จำนวนสูงสุด ทรัพยากรเริ่มต้น) เป็นค่าทดสอบ ปรับได้ใน `js/buildings.js`

## หมายเหตุเรื่อง Phaser
- เกาะยัง bake ลง canvas ด้วย `js/terrain.js` แล้วส่งเข้า Phaser เป็น texture (`textures.addCanvas`) ต้นไม้/ภูเขา/หินเป็น `Image` ที่ `setDepth(y)` เพื่อเรียงความลึก
- ขนาด chunk ต้อง **ไม่ใช่** เลขยกกำลัง 2 (ใช้ 2040) ไม่งั้น Phaser จะตั้ง wrap = REPEAT แล้วเกิดเส้นที่ขอบ chunk
- ภาพพื้นฝังเป็น data URL ใน `textures.js` เพราะ Chrome ไม่ให้ WebGL ใช้ภาพที่โหลดจาก `file://` — ถ้าเปลี่ยนภาพพื้น ให้รัน `python tools/embed_textures.py`
- ถ้าภายหลังอยากใช้ npm + Vite: `npm create vite@latest`, `npm install phaser@3.90.0` แล้ว `import Phaser from 'phaser'` (ตอนนั้นจะโหลดภาพตรง ๆ ได้ ไม่ต้องใช้ textures.js)
